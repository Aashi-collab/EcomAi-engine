# 🛒 Ecom AI Engine

An ML-powered E-commerce Backend built using FastAPI that provides product APIs, search functionality, and intelligent product recommendations using machine learning.

---

## 🚀 Features

- 📦 Get all products
- 🔍 Search products by name
- 🎯 Filter products by category and price
- 🤖 ML-based product recommendation system
- ⚡ FastAPI backend with high performance
- 🌐 Deployed on cloud (Render)

---

## 🧠 Machine Learning

This project uses:

- **TF-IDF Vectorization**
- **Cosine Similarity**

To recommend similar products based on:
- Product name
- Category
